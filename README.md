# Task-Project-Management
Full-stack task and Project management app using HTML, CSS, JS and backend is Express.js, MySQL, with CRUD operations, priority gtracking, and task filtering


#  Features
- Create, update, delete tasks (CRUD)
- Priority level for tasks
- Deadline tracking
- Search and filter tasks.
- Sorting tasksby priority or deadline.

# Techstack
- Frontend: React.js, HTML, CSS, Javascript
- Backend: Express.js
- Database: MySQL

# Project structure
- frontne/ ->react app
- backend/ -> express server
- database.sql -> mysql

# How to run
1. Clone the repository
2. Install the repositories in frontend and backend.
   ```bash
   npm install
3. Start the backend server
   - node server.js
4. Start frontend
   - npm start
